# Nasrin A — New Portfolio

This is a brand-new static portfolio website, separate from the previous Next.js portfolio. It uses plain HTML, CSS and JavaScript, so there is no npm install or Next.js build step.

## Preview locally
Open `index.html` in a modern browser.

## Deploy to Vercel
1. Create a **new GitHub repository** (do not reuse the old repository).
2. Upload the contents of this folder to the repository root, keeping `assets/`, `index.html`, `styles.css`, `script.js`, and `data.js` in place.
3. In Vercel, import that new repository.
4. Choose Framework Preset **Other**. Leave Build Command empty and set Output Directory to `.` if Vercel asks.
5. Deploy.

## Important privacy note
The documents folder includes the PDFs supplied for this portfolio, including offer letters and older resumes, as requested. Public deployments make these files accessible to anyone with the URLs. Review them and remove any private document before deployment. The site UI does not display a phone number, but some included PDFs may contain one.

## Contents
- `index.html`: full website
- `styles.css`: responsive design
- `script.js` and `data.js`: project, experience, certificates and document rendering
- `assets/images/`: supplied certificate and project images
- `assets/documents/`: supplied PDF documents
